## Dataset

This project uses the FER2013 (Facial Expression Recognition 2013) dataset, originally released as part of the Kaggle "Challenges in Representation Learning: Facial Expression Recognition Challenge" conducted during the ICML 2013 Workshop on Challenges in Representation Learning. The dataset contains 35,887 grayscale facial images (48×48 pixels) labelled across seven emotion categories. :contentReference[oaicite:0]{index=0}
